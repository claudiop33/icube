Documentação Icube v0.8.0

Linguagem de script estaticamente tipada com banco de dados, decimal, IA e structs embutidos. Roda em Linux e Windows. Feita para automatizar negócios.

1. Visão Geral

Icube é uma linguagem de script com banco de dados, decimal nativo, IA local e structs com métodos embutidos. Um único binário entrega tudo.

Princípios de Design

PrincípioDescrição
SimplicidadeSintaxe minimalista, sem ambiguidade
Segurança de tiposErros detectados antes da execução
Segurança SQLParâmetros vinculados previnem injection
Precisão monetáriaTipo decimal nativo (28 dígitos)
Nulidade explícitaPropagação estilo SQL (null + 1 = null)
OOP mínimaStructs + métodos, sem herança
IA localIntegração com Ollama, sem enviar dados

Pipeline de execução

    ↓
Lexer → Tokens
    ↓
Parser → AST
    ↓

    ↓

    ↓
PostgreSQL / MySQL + Ollama + stdout

2. Instalação

Pré-requisitos

  • Rust 1.75+ (instale via rustup.rs)
  • PostgreSQL 14+ e/ou MySQL 8+ (opcional)
  • Ollama (opcional, para IA)

Linux

# Dependências do sistema
apt install -y build-essential pkg-config libssl-dev

# Clonar e compilar
git clone https://github.com/claudiop33/icube.git
cd icube
cargo build --release

# Verificar
./target/release/icube --version
# icube 0.8.0

Windows

git clone https://github.com/claudiop33/icube.git
cd icube
cargo build --release

.\target\release\icube.exe --version
# icube 0.8.0

Ollama (opcional)

curl -fsSL https://ollama.com/install.sh | sh
ollama serve &
ollama pull llama3

7. Controle de Fluxo

if / else

if idade >= 18 {
    print("Maior");
} else if idade >= 12 {
    print("Adolescente");
} else {
    print("Criança");
}
A condição precisa ser bool. Não aceita int como em C.

while / for

let i = 0;
while i < 5 {
    print(i);
    i = i + 1;
}

for n in [1, 2, 3] {
    print(n);
}

break / continue

for n in [1, 2, 3, 4, 5] {
    if n == 3 { break; }
    if n % 2 == 0 { continue; }
    print(n);
}
// 1

8. Funções

fn saudar(nome: string) {
    print("Olá,", nome);
}

fn dobro(n: int) -> int {
    return n * 2;
}

fn calcular_total(preco: decimal, qtd: int) -> decimal {
    return preco * qtd;
}
Escopo isolado: funções não enxergam variáveis externas. Passe por parâmetro.

Recursão

fn fatorial(n: int) -> int {
    if n <= 1 { return 1; }
    return n * fatorial(n - 1);
}

Chamar antes de declarar

print(quadrado(5));  // funciona

fn quadrado(n: int) -> int {
    return n * n;
}

9. Structs e Métodos 🆕

Novo em v0.8.0. Tipos definidos pelo usuário com schema validado e métodos.

Declarar struct

struct Ponto {
    x: int,
    y: int,
}

struct Cliente {
    nome: string,
    idade: int,
    saldo: decimal,
}

Criar instância

let p = Ponto { x: 10, y: 20 };
print(p.x);      // 10
print(p.y);      // 20
Validação: todos os campos devem ser informados, e o tipo de cada campo é verificado em compilação.

Métodos

fn Cliente.maior_idade(self) -> bool {
    return self.idade >= 18;
}

fn Cliente.aplicar_bonus(self, pct: int) -> decimal {
    return self.saldo * (100 + pct) / 100;
}

O self é implícito com o tipo da struct — não precisa declarar self: Cliente.

Chamar métodos

let ana = Cliente { nome: "Ana", idade: 30, saldo: 1500.00 };

if ana.maior_idade() {
    print(ana.nome, "tem bônus de", ana.aplicar_bonus(10));
}
// Ana tem bônus de 1650

Métodos chamando métodos

struct Conta {
    saldo: decimal,
}

fn Conta.tem_saldo(self) -> bool {
    return self.saldo > 0;
}

fn Conta.sacar(self, valor: decimal) -> decimal {
    if !self.tem_saldo() {
        throw "sem saldo";
    }
    return self.saldo - valor;
}

Tipos aninhados

struct Endereco {
    rua: string,
    cidade: string,
}

struct Cliente {
    nome: string,
    endereco: Endereco,
}

let c = Cliente {
    nome: "Ana",
    endereco: Endereco { rua: "Rua A", cidade: "SP" },
};

print(c.endereco.cidade);  // SP

Duck typing (sem herança)

Basta que o método exista:

struct Cliente { saldo: decimal }
struct Fornecedor { saldo: decimal }

fn Cliente.credito(self) -> decimal {
    return self.saldo * 1.2;
}

fn Fornecedor.credito(self) -> decimal {
    return self.saldo * 0.9;
}

fn processar(entidade, valor: decimal) {
    if entidade.credito() >= valor {
        print("Aprovado");
    }
}

O que NÃO tem (por design)

  • ❌ Herança (extends)
  • ❌ Interfaces (interface)
  • ❌ Polimorfismo via tipos
  • ❌ Getters/setters mágicos
  • ❌ Construtores

Duck typing cobre a maioria dos casos de polimorfismo. Menos complexidade, mais produtividade.

13. exec() e exec_run() 🆕

Novo em v0.7.8. Execute comandos externos e scripts shell.

exec(cmd) — captura saída

let saida = exec("ls -la");
print(saida);

let data = exec("date");
print("Hoje é:", data);

Se o comando falhar (exit != 0), lança exceção com o stderr.

exec_run(cmd) — só exit code

let code = exec_run("./teste.sh");
if code == 0 {
    print("script ok");
} else {
    print("falhou com código", code);
}

Com try/catch

try {
    exec("ls /nao/existe");
} catch e {
    print("Capturado:", e);
}
// Capturado: comando falhou (exit 2): ls: cannot access...

Multiplataforma

Usa sh -c no Linux/macOS e cmd /C no Windows. Funciona igual nos dois.

⚠️ Segurança no servidor web: exec() é bloqueado por padrão em icube --serve. Habilite só se confiar nos usuários: 
ICUBE_ALLOW_EXEC=1 icube --serve 9000
Em CLI e REPL, funciona sempre.

14. Banco de Dados

Configurar

# .env
ICUBE_DB_URL=postgres://usuario:senha@localhost:5432/meubanco

Conectar

db.connect_default();              // via ICUBE_DB_URL
db.connect_named("producao");    // via icube.toml
db.connect("postgres://...");   // direto
Idempotente: chamar connect_default() várias vezes é seguro. Só conecta uma vez.

Executar (INSERT/UPDATE/DELETE)

db.execute(
    "INSERT INTO usuarios (nome, idade) VALUES ($1, $2)",
    ["Ana", 30]
);

db.execute("DELETE FROM usuarios WHERE id = $1", [5]);

Consultar

let todos = db.query("SELECT * FROM usuarios ORDER BY id");
for u in todos {
    print(u["id"], u["nome"]);
}

let um = db.query_one(
    "SELECT * FROM usuarios WHERE id = $1",
    [5]
);

if um == null {
    print("Não encontrado");
} else {
    print("Nome:", um["nome"]);
}

Parâmetros seguros

BancoSintaxe
PostgreSQL$1, $2, ...
MySQL? (na ordem)
Nunca concatene valores no SQL. Use sempre placeholders para prevenir SQL injection.

15. Transações

db.connect_default();
db.begin();

try {
    db.execute(
        "INSERT INTO pedidos (cliente, valor) VALUES ($1, $2)",
        ["Ana", 150.00]
    );
    db.execute(
        "UPDATE estoque SET qtd = qtd - 1 WHERE produto = $1",
        ["Caneta"]
    );
    db.commit();
    print("Pedido registrado");
} catch e {
    db.rollback();
    print("Falhou, desfeito:", e);
    throw e;
}

Rollback automático

  • Processo morre com transação aberta
  • exit() chamado com transação aberta
  • Timeout no servidor web

16. Tipo Decimal

Precisão de 28-29 dígitos. Ideal para dinheiro.

Por que decimal?

// ❌ float perde precisão
print(0.1 + 0.2);   // 0.30000000000000004

// ✅ decimal preserva
let a: decimal = 0.1;
let b: decimal = 0.2;
print(a + b);         // 0.3

SQL com NUMERIC

let r = db.query("SELECT preco FROM cotacoes");
for c in r {
    print(c["preco"]);  // 240.99 (não null!)
}

19. Servidor Web

Iniciar

icube --serve 9000                          # HTTP
ICUBE_TLS_AUTO=1 icube --serve 9000         # HTTPS self-signed
ICUBE_TLS_CERT=/path/cert.pem \
ICUBE_TLS_KEY=/path/key.pem \
icube --serve 443                            # HTTPS real

Sessões

  • Cada sessão tem seu próprio Evaluator (variáveis + structs + funções persistem)
  • Session ID com 64 hex chars (32 bytes) via OsRng
  • Cookie icube_session (HttpOnly, SameSite=Lax, Secure em HTTPS)
  • TTL de 1 hora

20. Autenticação

  • Senhas com Argon2id
  • Login via POST /api/login
  • Cookie de sessão após sucesso
  • 3 papéis: administrator, colaborador, visitante
  • Rate limit: 30 req/min por IP

Bootstrap do admin

# Configure dois fatores
export ICUBE_DEV_RESET=1
export ICUBE_DEV_RESET_TOKEN=meutoken123
icube --serve 9000

# Em outro terminal
curl -X POST http://localhost:9000/api/dev/reset-admin \
  -H "Content-Type: application/json" \
  -d '{"password":"nova123","token":"meutoken123"}'
Remova ICUBE_DEV_RESET do ambiente após usar.

21. Segurança

Implementado

ItemStatus
Senhas com Argon2id✅
SQL injection via $1, $2✅
Cookie HttpOnly + SameSite=Lax✅
Cookie Secure (HTTPS)✅ condicional
Session ID CSPRNG (OsRng)✅

Timeout de execução✅
Dev-reset com token + tempo constante✅

Boas práticas em produção

  1. Use HTTPS real (Let's Encrypt)
  2. Não defina ICUBE_INSECURE_COOKIE
  3. Remova ICUBE_DEV_RESET do ambiente
  4. Mantenha ICUBE_REQUIRE_AUTH=1
  5. Nunca habilite ICUBE_ALLOW_EXEC=1 em servidor público
  6. Configure nginx como proxy reverso (TLS + HSTS + CSP)

22. Limitações Conhecidas

Linguagem

  • Sem switch/match
  • Sem herança de structs
  • Sem closures
  • Sem módulos/import
  • Sem push/pop em listas
  • Sem interpolação de string
  • Sem +=, -=, etc.

Tipos

  • Sem uuid, json (JSONB)
  • Arrays heterogêneos viram list<any>

Banco

  • Apenas um pool ativo por vez
  • Sem transações aninhadas (savepoints)
  • Colunas UUID, JSONB retornam null

IA

  • Sem streaming
  • Timeout 180s
  • Sem cache

Ferramental

  • REPL single-line (sem multi-linha)
  • Sem LSP / autocomplete em editores
