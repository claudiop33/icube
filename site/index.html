A linguagem com banco e IA
no coração.

Icube é uma linguagem de script estaticamente tipada com PostgreSQL, decimal nativo e IA local embutidos. Simples, segura, feita para automatizar negócios.

🚀 Começar agora 📖 Ver no GitHub
exemplo.icb
// Analisa cotações com IA
db.connect_default();

let cotacoes = db.query(
  "SELECT peca, preco FROM cotacoes WHERE status = $1",
  ["pendente"]
);

for c in cotacoes {
  let analise = ai.ask(
    "O preço R$ " + (c["preco"] as string) + " está justo?"
  );
  print(c["peca"], "->", analise);
}

Por que Icube?

Tudo o que você precisa em uma única linguagem. Sem dependências externas, sem complexidade.

🗄️

Banco de dados nativo

PostgreSQL e MySQL integrados. Parâmetros seguros ($1, $2) e transações atômicas.

💰

Decimal de verdade

Tipo decimal com 28 dígitos. Sem os erros de arredondamento do float.

🤖

IA local integrada

Chame ai.ask() direto no script. Suporte nativo a Ollama e modelos locais.

🛡️

Tipagem estática

Erros detectados antes de rodar. Nulidade explícita (T?) e casts seguros.

⚡

Servidor web embutido

HTTP/HTTPS, autenticação Argon2id, sessões, TLS e rate limiting no mesmo binário.

📦

Zero configuração

Um binário. icube script.icb e pronto. REPL interativo incluso.
