🐣 Icube

Linguagem de script estaticamente tipada com banco de dados, decimal e IA embutidos. Simples, segura e feita para automatizar negócios.

v0.7.7 ✓ PostgreSQL + MySQL ✓ Decimal nativo ✓ IA local (Ollama)
Começar agora Ver no GitHub →
exemplo.icb 
// Conecta ao banco e consulta cotações
db.connect_default();

let cotacoes = db.query(
    "SELECT peca_nome, preco FROM cotacoes WHERE status = $1",
    ["pendente"]
);

for c in cotacoes {
    // IA analisa o preço
    let analise = ai.ask(
        "O preço R$ " + (c["preco"] as string) + " está justo?"
    );
    print(c["peca_nome"], "->", analise);
}

Por que Icube?

🗄️

Banco de dados nativo

Consultas SQL com parâmetros seguros ($1, $2) e transações atômicas. Sem ORM, sem surpresas.

💰

Decimal de verdade

Tipo decimal com 28 dígitos de precisão. Perfeito para dinheiro, contabilidade e cotações.

🤖

IA integrada

Chame ai.ask() direto no script. Integração nativa com Ollama e modelos locais.

🛡️

Tipagem estática

Erros detectados antes da execução. Nulidade explícita (T?) e casts seguros.

⚡

Servidor web embutido

HTTP/HTTPS, autenticação Argon2id, sessões e rate limiting no mesmo binário.

📦

Zero configuração

Um único binário. icube script.icb e pronto. REPL interativo incluso.

Instalação rápida

Compile a partir do código-fonte (Rust 1.75+)

$ cargo build --release
